## Naming principles (apply to future apps)

1. **Rooted or coined, never floated.** If the name is not rooted in Afro-Atlantic substrate (Yoruba, Kemet, Vodun, Lucumí, Palo, Candomblé, Rastafari, Maroon, Akan, Dogon, Bantu, Ethiopian etc.), it must be explicitly coined at a rupture-point you can name.

2. **One syllable is a gift.** Hu, Dá, Òrò, Heka, Ogun, Kọ́ — all short. Short names scale. Reserve long names for the surface-level apps where they carry weight (Sankoré, Marronage).

3. **The name must do what the app does.** Ibis writes. Hu utters. Ogun forges. Heka activates. Legba routes. If the metaphor has to be argued for, the name is too loose.

4. **Check the tradition is still living.** Kemet is reclaimed (Diop, Pan-African scholarship). Vodun is active. Yoruba is active. Rastafari is young but explicit. Don't pick a dead-language term from a tradition you can't name a living practitioner of.

5. **Respect what's taken.** Don't reuse a name that's an era/project/album inside your body of work (Gelede), or already assigned in the ecosystem (Ọnà, Nommo).

6. **Reserve before you burn.** Sekhem is too good to burn on the wrong slot. Hold names back for surfaces that actually earn them.

7. **Let the name teach.** A user who meets **Hu** or **Heka** or **Abeng** for the first time is invited into a cosmology. That's the point. The unfamiliarity is the moat.

**Igbo (southeastern Nigeria — primary substrate layer 1):**
- *Odinani / Odinala* — "that of the land"; the Igbo religious-philosophical cosmology as a whole
- *Chi* — personal destiny-spirit, inner guardian; no two chi are alike
- *Chukwu / Chineke* — supreme god, the creator

## Decision protocol

When renaming:

1. Hold the candidate for at least a week. Speak it aloud repeatedly. Does it still carry?
2. Type it in context: "open in Heka", "send to Ogun", "voice generated by Hu". Does it read?
3. Check spelling-ergonomics: can users type it? (Hu — trivial. Ọnà — the dot-under-o hurts.)
4. Check collision with existing names in your body of work (eras, albums, characters).
5. Check one more time that the tradition is a living one you respect enough to carry.
6. If all five hold, commit. Change the repo name, the URL, the UI, the env vars — make the switch complete in one pass.

**You do not need to rename everything at once.** Pick one app at a time. Live with the new name in a single surface. Then propagate.
